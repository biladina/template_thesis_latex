% Daftar Isi is its own small roman-numbered front matter: page "i",
% hidden on its own opening page (proposal.cls's \@makeschapterhead)
% but still listed as an entry inside the Daftar Isi it belongs to.
% Bagian content then starts arabic numbering over at 1.
%
% \addcontentsline must come after \pagenumbering (so it reads "i",
% not whatever the cover left \c@page at) but BEFORE \tableofcontents:
% \tableofcontents's own \chapter* is what actually breaks to this
% page and drops hyperref's link anchor here, so without \phantomsection
% first, this entry's bookmark would point at whatever page/anchor
% came before it instead of at Daftar Isi itself.
\pagenumbering{roman}
\phantomsection
\addcontentsline{toc}{chapter}{\contentsname}
\tableofcontents
% Bagian no longer force their own page break (see proposal.cls), so
% without this the first bagian would start right under a short Daftar
% Isi listing instead of on its own page.
